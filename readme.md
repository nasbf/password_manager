# Overview


This program was developed to apply learning concepts about Kotlin language, concepts like (variables, expressions, conditionals, loops, classes and functions)

This program is a basic password manager created with Kotlin, that let the user view all accounts stored, add an account, change any password and find a website 
with its respectively data.
